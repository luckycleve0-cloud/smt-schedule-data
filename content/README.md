# content/

Автоматически собирается `content_parser.py` через GitHub Actions раз в час.

| Файл | Что внутри |
|---|---|
| `feed.json` | VK-посты + новости сайта, категории `events`, `news`, `session`, `practice` |
| `session.json` | сессия, экзамены, консультации |
| `practice.json` | расписание практики и замены |
| `archive.json` | удалённые/старые материалы, хранится год |
| `meta.json` | время обновления, счётчики, ошибки источников |

Правила:

- фото не перезаливаются: в JSON только официальные URL VK/сайта;
- VK-посты без токена не добавляются, сайт продолжает обновляться;
- архив пополняется, когда пост исчез из текущей ленты;
- JSON отдаётся приложению через GitHub raw, jsDelivr и Yandex S3.
